# Kalkulator Retro Multifungsi

Kalkulator Neumorphic multifungsi berbasis web yang dibangun dengan antarmuka yang modern, dinamis, dan responsif. Aplikasi ini memiliki berbagai mode perhitungan untuk membantu berbagai macam kebutuhan matematis hingga konversi.

Dibuat oleh **Muhammad Rafly Romeo Nasution**.

## 🌟 Fitur Utama

- **Mode Standard**: Perhitungan dasar sehari-hari (+, -, *, /).
- **Mode Scientific**: Perhitungan lanjutan, fungsi trigonometri, logaritma, akar, dan pangkat.
- **Mode Programmer**: Konversi sistem bilangan antara HEX (Heksadesimal), DEC (Desimal), OCT (Oktal), dan BIN (Biner).
- **Mode Currency**: Konversi mata uang dengan nilai tukar yang mendukung berbagai mata uang (menggunakan API).
- **Mode Temperature**: Konversi suhu antara Celsius (°C), Fahrenheit (°F), dan Kelvin (K).
- **Dark Mode / Light Mode**: Tampilan yang bisa disesuaikan, didukung dengan desain Neumorphic / Retro.
- **History Log**: Menyimpan riwayat perhitungan yang telah dilakukan, lengkap dengan opsi untuk menghapus (Clear).
- **Responsif**: Dapat diakses dengan nyaman melalui perangkat Desktop maupun Mobile.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur utama antarmuka.
- **CSS3 & Tailwind CSS**: Styling menggunakan Tailwind via CDN untuk utilitas class dan desain Neumorphic yang kustom.
- **Vanilla JavaScript**: Logika perhitungan komprehensif, manajemen fungsi kalkulator, dan interaktivitas.

## 📂 Struktur Projek

```plaintext
kalkulator-retro-html/
├── .git/        # Folder konfigurasi Git (jika menggunakan repository lokal)
├── index.html   # File utama HTML yang berisi struktur kalkulator dan layout antarmuka
├── script.js    # File logika JavaScript yang menangani perhitungan, fungsionalitas dan DOM
├── styles.css   # File CSS kustom tambahan untuk styling khusus
└── README.md    # Dokumentasi projek ini
```

## 🚀 Cara Menjalankan Projek

1. Pastikan Anda telah mengkloning (clone) atau mengunduh folder projek ini ke komputer Anda.
2. Buka folder projek `kalkulator-retro-html`.
3. Buka file `index.html` langsung di browser web Anda (Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari).
4. Tidak diperlukan proses instalasi dependensi atau *build step* tambahan karena projek ini langsung jalan (*plug-and-play*).
